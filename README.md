# hfustercabre/tap

Homebrew casks for my Mac apps.

## AutoHush

[AutoHush](https://github.com/hfustercabre/AutoHush) is a small menu bar app that pauses your music while other apps play, and brings it back when they stop.

```bash
brew install --cask hfustercabre/tap/autohush
```

AutoHush is signed but not notarized by Apple, so the cask removes the download quarantine and it opens without the usual extra confirmation. It installs its own updates; `brew upgrade --cask autohush` works too. To remove it: `brew uninstall --cask autohush`.

The cask is updated by AutoHush's release process. Please report problems in [AutoHush's issues](https://github.com/hfustercabre/AutoHush/issues).
